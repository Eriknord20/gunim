Noto Sans Symbols and Noto Sans Symbols 2, from Debian's fonts-noto-core,
under the SIL Open Font License 1.1 (https://openfontlicense.org). The
WebAssembly build embeds them for the symbols Go Sans lacks (▶ ◀ ⏪ ⏩ ⚙),
since a browser gives Go no system fonts to fall back on.

Inter 4.1, regular and semibold (Inter-Regular.ttf and Inter-SemiBold.ttf,
from extras/ttf in the release's Inter-4.1.zip, unchanged), by The Inter
Project Authors, under the SIL Open Font License 1.1 in LICENSE-Inter.txt
(https://github.com/rsms/inter). Every build embeds them for the touch kit,
text.Inter, which reads each on its first use.
